# Original compositing fixture

`composite-animation.gif` is an original project test asset: three 96×64 colored/numbered canvases with transparent regions, 200/400/600ms delays, and restore-to-background disposal. It was created for this repository, uses no external media, and may be used under the repository's terms. It exercises native/shared selected-frame rendering, varying alpha footprints and decoder disposal; it is not a visual benchmark or third-party sample.
