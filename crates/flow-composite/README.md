# gpui-flow-composite

Toolkit-independent, bounded CPU vector/selected-image-frame isolation with locked tiny-skia 0.11.4 (BSD-3-Clause). The adapter reuses the existing Kurbo/Lyon stroke triangle producer. It does not emulate an offscreen target using GPUI `paint_layer`.

The document contract adds `Style.blend_mode` (`pass_through`, `normal`, `multiply`, `screen`) and `DisplayObject.mask` (`none`, `alpha`). Missing fields preserve legacy defaults. An alpha mask must be a direct Group child; it starts a stable z-ordered sibling run and does not draw itself. Another mask ends the previous run. Geometric picking is unchanged.

`scene_units` validates the scene and preserves the presented tree's painter order, replacing an entire isolated subtree with one `DomainSource`. `rasterize` uses an immutable domain, exact viewport/device-grid geometry, a shared `PixelBudget` and a cancellation flag. It returns only a complete premultiplied RGBA `CpuFrame`, `None` for empty/offscreen output, or an explicit error. SceneView consumes it on one background worker, uploads through real GPUI RenderImage/paint_image, and exposes composite diagnostics. This crate remains independently testable without GPUI. See [production integration and native validation](../../docs/compositing.md).

Supported domains: Rect (including rounded), Ellipse, Line, Polygon, Star, Path, Pen, Group and fixed-size Box/Frame. Curves use tiny-skia path primitives; multiple fills and shared centered stroke meshes retain painter order. Every object/group opacity is applied once to its entire contents. Normal groups isolate the backdrop; pass-through groups share their CPU parent; multiply/screen operate on actual pixels inside the domain. Opaque alpha-mask runs flush independent blend children to the CPU parent, matching Leafer's mask algorithm. Translucent runs composite first and apply the mask once.

Text and Custom inside a domain reject the complete domain. Image snapshots use host-supplied `ImageInputs` through `rasterize_with_images`; missing/invalid inputs reject the entire domain. `rasterize` remains available for vector-only input. Rounded Box/Frame clips inherited from outside a domain are supported and applied once after its contents. External multiply/screen roots are rejected: native siblings, the host background, grid and UI aren't captured. Place any required background vector inside a normal Group. SceneView supplies elapsed-time GIF/WebP snapshots; this headless crate owns no playback clock. There are no text producer, eraser, shadow, grayscale/path/clipping mask, pixel-picking, tiling, automatic resolution reduction, wide-gamut or linear-light guarantees. Selection/layout bounds conservatively include masks and their content rather than adopting Leafer's mask bounds.

Defaults (callers can only lower these): 4096 per axis, 4,194,304 pixels per domain; 128 MiB explicit simultaneous surfaces/retained outputs; 32,000,000 conservative surface-write pixels per request; 8 domains per request, 512 nodes per domain, 16 levels, 64 mask runs, 65,536 source points per shape, 262,144 total source points and stroke triangles, 256 gradient stops per paint, existing 32 paints per object. Full-surface accounting intentionally rejects some large multi-paint scenes even if the painted shapes are small. Coordinates must be finite/invertible and transformed control points within ±1,000,000 device pixels. GPUI/cache-owned original decoded images, private kernel allocations and GPU memory are outside the explicit surface budget, so this is not a hard process-memory limit. A single tiny-skia operation is not preemptible; cancellation is checked between operations.

Stroke contours use the existing 0.1 local-unit approximation; rounded primitives/clips share existing bounded contours. Antialiasing and gradients need not match the previous native adapter byte-for-byte. Premultiplied output must be unpremultiplied and converted to straight BGRA exactly once at GPUI upload; never apply group opacity a second time.

References: [Leafer blend contract](https://www.leaferjs.com/ui/reference/UI/blendMode.html), [mask contract](https://www.leaferjs.com/ui/reference/UI/mask.html), [pinned upstream mask implementation](https://github.com/leaferjs/leafer-ui/blob/1e11641d3ea6b0211c83447268a90b8d58feec25/packages/partner/mask/src/index.ts). This is an independent adapter to existing kernels, not an imported Leafer renderer.

SceneView caps accepted/candidate batches at 32 MiB each and retirement at 32 MiB within the shared 128 MiB explicit surface ceiling. Validation/snapshot and some stroke work remain on the UI thread; no frame-time guarantee is made. A pass-through mask Group is not an implicit isolation boundary for blends against native content; those escaping blend cases are explicitly rejected.

Static inputs are immutable validated premultiplied RGBA, constructed from straight BGRA with `StaticImage::from_straight_bgra`. Tiny-skia bilinear patterns use decoded aspect for Contain/Cover/Fill; image layout/style/alpha/affine/clip semantics are documented in the production integration guide. `PixelBudget::discard_frame` consumes a frame produced with that budget and releases its retained bytes without resetting work or peak accounting. GPUI-owned decoded originals and cache memory are outside the adapter's explicit surface budget. Converted copies are counted and shared by identity; SceneView caps conversion batches at 32 MiB.

SceneView deduplicates converted inputs by `(GPUI ImageId, frame_index)` and caps these owned copies at 32 MiB. Budget retries preserve successful current-domain output and terminal diagnostics; only memory failures are eligible after a real byte release. Dropped output releases its budget charge. See [static image inputs and validation](../../docs/compositing.md#static-decoded-image-input).

Fixed-size Box/Frame support uses existing vector contours/stroke meshes, complete local opacity, visible Box overflow and rounded Frame child clips. Parent fill/stroke precede children, preserving the current native Scene order (Leafer's conditional fill/children/stroke phase is not implemented). Own outer strokes are never clipped by child overflow. Clips preserve pass-through CPU blend backdrops and are budgeted; see [container semantics and limits](../../docs/compositing.md#fixed-size-painted-containers).

SceneView shares a bounded runtime playhead between native and CPU image routes, with pause/resume/seek, generation resets and freeze/resume visibility behavior. Animation samples coalesce without cancelling admitted workers; only current-frame pixels are copied. Encoded finite loop counts, APNG animation, rate and editor-timeline coupling remain outside this slice. See [animated images](../../docs/compositing.md#animated-images-and-runtime-controls).
