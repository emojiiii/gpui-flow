## API and exact mode meaning

The shared `Shadow` adds `spread: f32` (finite ±4096, default0), JSON `box: bool` (Rust `r#box`, default false), and `scale_fixed: bool` (default false). `Shadow::new(x,y,blur,color)` remains the constructor with those defaults. Old JSON reads with default fields; new native JSON stores them. Older binaries are not promised to accept those new fields, and adding public Rust fields breaks external struct literals. Existing x/y/blur/color and array validation/count limits remain; invalid retained hidden/transparent entries reject atomically rather than truncating.

Spread is centered affine resampling of original source alpha, **not morphological dilation or erosion**. Keep a geometric reference rectangle R separate from complete actual-alpha capture support S. Leaf and fixed Box/Frame references use their own pre-effect paint/stroke geometry, with fixed strokes resolved in the supported context. Group references union retained descendant pre-effect geometry, including structural child clipping, hidden geometry and Box overflow, but excluding descendant effects and eraser contributions. A child's asymmetric shadow enlarges capture support without moving the parent's pivot. A paintless Frame retains its declared reference even when only child blur halo enters its clip.

Let W/H be the owner-local reference dimensions, C the center of its physical transformed AABB, s the positive logical camera×world similarity scale and d the separate device scale. Compensation is `f = scale_fixed ? 1/max(1,s) : 1`. DPR never enters that cap. Outer spread factors are `kx=1+2*spread*f/W`, `ky=1+2*spread*f/H`; inner uses the opposite sign. These are canvas-axis factors, including for a rotated non-square element. Source shape size does not itself become scale-fixed. Flow keeps its existing rotated local-vector offset: physical delta is the physical linear transform of (x,y), multiplied by f. Shadow sigma retains its half-radius rule, `blur * physical_scale * f / 2`, with zero or the admitted positive [.001,64] band and all existing transform/offset caps.

For nonzero factors, backward-sample original A8 alpha bilinearly at `C + ((q-C)/k)`, treating exterior as transparent; resample before Gaussian and offset. Negative factors reflect rather than silently clamp. An exactly zero axis has zero projected alpha: outer contributes nothing and inner tints original alpha. This singular behavior is an explicit Flow rule, not a tested browser claim. Nonzero spread on a nonempty source with missing/zero reference dimensions rejects through the applicable Scene/geometry or composite `InvalidShadowReference` gate; it never substitutes epsilon or padded surface dimensions. Structural emptiness adds no invented rectangle.

If A is original untransformed/unoffset source alpha at the final output pixel and B is the projected, blurred and offset alpha, outer box coverage is `B*(1-A)`, with the existing integer rounding. Plain outer coverage is B; inner is `A*(1-B)`. Inner `box` is intentionally stored but inert. Box does not mean rectangular alpha and does not remove previous shadow layers or the final source. Half-alpha originals retain fractional knockout. Each layer samples the same original source independently; its own siblings never feed it.

## Bounded accounting and intentional legacy correction

All global ceilings remain: 4096 pixels/axis, 4,194,304 pixels/surface, 128 MiB known working set, 32 million cumulative conservative work units, depth16, plus existing node/domain/path/layer limits. Model validity does not promise that every combination fits them. Gaussian calls remain bounded but non-interruptible internally; extraction/resampling/tint row loops and filter boundaries check cancellation.

For original capture N pixels, transformed/filter M pixels and output Q pixels, the mode keeps a conservative `5N + FilterBytes(M) + 4Q` allowance. Recursive source rendering occurs while that reservation is live. Work includes `12N + FilterWork(M) + 16M + 16Q`, destination compositing and every repeated descendant capture. Outer collapse skips its pixel contribution; planning/validation can still reject invalid sources or parameters. Runtime and no-pixel admission must share the immutable plan and schedule, restore retained accounting on failure and publish no partial snapshot.

The A8 filter now includes a conservative `64*K²` allowance for positive-sigma symmetric-kernel trimming, where `K=2*(ceil(4*sigma)+2)+1`. Zero sigma does not receive it. This also applies to default shadow layers: default pixel intent is preserved except for the specific correction below, but an old request near the work ceiling may reject earlier. No cap was increased. Accounting is not a whole-process/GPU-memory or wall-time guarantee.

The locked image0.25.10 one-tap A8 defect is deliberately corrected: for positive admitted sigma, only an **exact zero adjacent f32 Gaussian weight** selects mathematical identity. Nonzero weights still use the unmodified dependency; zero blur remains a true bypass. The prior right-shift/first-row failure and adjacent representable-f32 boundary tests must remain in the evidence. A positive authored radius that narrows to zero is rejected, not silently treated as authored zero. Actual retained f32 sigma controls support/kernel accounting. Mode-default parameter composition retains its established matrix-narrowing path; active modes retain the explicit logical/device provenance. This is not a general image-library patch or browser-pixel promise.
