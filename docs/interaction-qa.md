# 交互修复验收记录

> 历史验证记录：旧 Studio 原生演示已于 2026-10-05 移除。本文的源码路径、命令、交互矩阵与结果仅对应当时版本，不是当前可运行入口或新工作台验收。当前入口见[入门](getting-started.md)，测试保留范围见[迁移说明](studio-retirement.md)。

日期：2026-09-30。环境：Linux 云端桌面，实际 GPUI `interactions` 示例窗口。以下记录针对本次插件化重构的工作树，不代表 Windows/macOS 或后续提交已通过。

## 已在真实窗口操作验证

- 从端口拖向空白处松开，随后继续移动鼠标：预览清除，边数保持 0，没有跟随残影
- 从端口拖到画布/窗口外松开，再回到画布：捕获清除，没有残留预览
- 在 100% 和 69% 缩放下，拖到兼容输入端口中心约 16 屏幕像素的位置：超过精确点击区域仍可吸附并创建连接
- 吸附时看到更大的亮色目标圆环，预览使用曲线并落在真实端口上；提交后的边不再跟随鼠标
- 关闭 snapping 后，同样的近端口松开不连接；精确落在端口中心仍能连接
- 关闭 connection 后，端口拖动不创建连接
- Number → String 的不兼容连接被拒绝，状态栏显示类型错误，没有新增边或残影
- Ctrl+Z 撤销连接；一次缩放节点操作可用一次 Ctrl+Z 恢复
- 点击节点后出现边框内的小方形缩放点，悬停显示对角缩放光标；不再使用 `◢` 字符
- 拖动缩放点只改变目标节点尺寸；拖动节点内容区只移动该节点，不会平移整个画布
- read-only 下移动、连线和 Delete 均不改图；选中节点不显示缩放点，端口显示禁止光标
- 单独关闭 resize 后，已选节点的缩放点消失
- locked 节点可选，但无法移动、删除，不显示缩放点
- Space + 拖动空白处平移整个视口，不改节点间的相对位置

测试使用示例内临时图，没有读取或修改用户项目文件。测试结束后关闭了窗口。

## 自动化验证

本次检查通过：

```bash
cargo test --locked -p gpui-flow-core --test connection
cargo clippy --locked -p gpui-flow-core --all-targets -- -D warnings
cargo test --locked -p gpui-flow --lib
cargo clippy --locked -p gpui-flow --all-targets --no-deps -- -D warnings
```

核心连接状态机 7 项测试通过，覆盖空白松开、松开后不复活、不同 zoom 的屏幕像素吸附、反向起拖归一化、类型/容量/重复/自连/环校验、删除源端口、缺失按键状态、取消和单次事务撤销。精确命中 API 的测试确保关闭独立吸附插件后不会暗中吸附。

UI 库 10 项单元测试通过，其中新增两项验证节点内容区命中不会落到背景、端口精确命中范围与吸附范围分离，以及缩放点命中随选择/权限/缩放正确变化。插件宿主还有独立的 reducer/策略测试，数量以相应测试结果为准。
